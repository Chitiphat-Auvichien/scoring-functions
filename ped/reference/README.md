# Reference `.fmt` files

`C6H6.fmt` and `C6H6_with_dummy_raman.fmt` were generated by the prior
`12_export_veda_fmt.py` (now archived at `ped/archive_python_ped/12_export_veda_fmt.py`,
Framework-1/reconstruct-equivalent to today's `ped/hessian_reconstruct.py`), then
manually opened in real `veda4e1.exe` and cross-validated: VEDA4's own recomputed
frequencies matched Gaussian's originals to ~0.02-0.3 cm⁻¹, with VEDA4's own
diagonality factor 81.72% and ⟨EPm⟩=81.51% after its EPm-maximizing coordinate
optimization.

These two files are the baseline `tests/test_veda_fmt_regression.py` diffs a freshly
generated Framework-1 `.fmt` against, to catch any future regression in the Hessian
reconstruction or `.fmt`-assembly logic.

The real VEDA4 session output (`.ved`/`.vdf`/`.dd2`) lives outside this git repo, at
`../../../veda4/c6h6_reconstructed.*` relative to `ped/`.
