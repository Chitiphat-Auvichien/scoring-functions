Score the normal modes of a molecule.

Seven scores per mode — Tx Ty Tz translation, Rx Ry Rz rotation, V_S stretch character — then a label: S stretching, B bending, SB mixed.

Both are required: a .log holds no bond list, and V_S is a sum over bonds. Connectivity is asked for, never guessed.

modes in file

One file, a few kB instead of megabytes. Download one from any result page, or convert in bulk with make_vsc.py. Format spec →

What the scorer actually reads

Required

element per atom→ atomic massall 7
coordinates→ COM, principal axesall 7
displacements→ the modeall 7
bond list→ per-bond termsV_S only

Never read

Frequency (a row label — zeroing it changes nothing), reduced mass, force constant, irrep, IR/Raman intensities, charge, multiplicity, basis set — and the Cartesian Hessian, which is the largest block in a VEDA .fmt and is not used at all.
