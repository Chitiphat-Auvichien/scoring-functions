Score the normal modes of a molecule.

Seven scores per mode — Tx Ty Tz translation, Rx Ry Rz rotation, V_S stretch character — then a label: S stretching, B bending, SB mixed.

{% if is_local %} {% endif %}

Both are required: a .log holds no bond list, and V_S is a sum over bonds. Connectivity is asked for, never guessed.

The mode set is detected from the file. If it holds 3N modes it is taken as the complete set, translations and rotations included, and the six external modes are found among them — nothing is constructed. If it holds 3N−6 (3N−5 when linear) it is taken as vibrations only, and the six ideal T/R references are constructed and added so a real vibration is never claimed for an external slot. Any other count is refused rather than guessed at.

One file, a few kB instead of megabytes. Download one from any result page, or convert in bulk with make_vsc.py. Format spec →
